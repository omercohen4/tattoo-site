# אתר הסטודיו

אתר בעמוד אחד: HTML, CSS ו-JavaScript רגילים, בלי שלב בנייה. מתפרסם דרך GitHub Pages מענף `main`.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `index.html` | כל התוכן של האתר |
| `assets/css/style.css` | העיצוב. הצבעים והגדלים מוגדרים למעלה, בחלק `Tokens` |
| `assets/js/main.js` | המתג סקיצה/קעקוע, הסינון לפי סגנון והאנימציות |
| `assets/vendor/` | GSAP ו-ScrollTrigger (ספריית האנימציות) |
| `assets/img/` | תמונות. כרגע זמניות |

## מה צריך להחליף לפני שעולים לאוויר

- כל טקסט בסוגריים מרובעים: `[סכום]`, `[username]` ועוד
- מספר הוואטסאפ: `972500000000` בקישורי `wa.me` (בפורמט בינלאומי, בלי 0 בהתחלה), ו-`050-000-0000` בטקסט
- הכתובת והשעות, גם בגוף העמוד וגם בבלוק `application/ld+json` שבראש `index.html`
- תמונות העבודות: לכל עבודה זוג תמונות באותה זווית, `work-N.jpg` (הקעקוע) ו-`work-N-stencil.jpg` (הסטנסיל הסגול), ביחס 4:5
- `assets/img/hero.svg` ו-`assets/img/portrait.svg` בתמונות אמיתיות, ואפשר להחליף את התמונה הראשית בסרטון קצר (יש הערה במקום הנכון ב-`index.html`)
- כשיהיה דומיין: לעדכן את הכתובת ב-`canonical`, ב-`og:url`, ב-`robots.txt` וב-`sitemap.xml`
